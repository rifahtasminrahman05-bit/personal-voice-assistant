Ethical hacking follows a methodology: reconnaissance, scanning, gaining access, maintaining access, and covering tracks — studied so defenders can break each phase.
Passive reconnaissance collects public information without touching the target: search engines, job postings, certificate transparency logs, public DNS records, and archived pages.
Active reconnaissance interacts with the target: ping sweeps, DNS queries, and banner grabbing reveal live hosts and software versions.
Network scanning maps hosts and open ports. Defenders run the same scans against their own networks to find exposure before attackers do.
Banner grabbing reveals service versions. Old versions with known CVEs are the fastest path into a network, so patching and inventory matter most.
A penetration test has clear rules of engagement: written authorization, scope boundaries, testing windows, emergency contacts, and a final report with findings ranked by severity.
The five kinds of findings in a pentest report: critical, high, medium, low, and informational. Each finding needs evidence, impact, and a concrete fix.
Recon tools overview: nmap maps hosts and services, theharvester collects emails and subdomains, whatweb fingerprints web technologies, and shodan indexes internet facing devices.
Packet analysis with wireshark shows what actually travels on the wire. Defenders use it to verify encryption, find leaking credentials in protocols like telnet or http basic auth.
Web testing with burp suite intercepts browser requests so testers can manipulate parameters and study how the server reacts. Defenders use the same view to design validation.
Password attacks come in types: dictionary attacks try common words, brute force tries everything, spraying tries one password across many accounts, and credential stuffing replays leaked pairs. Defenses: rate limiting, lockouts, multi factor authentication, and monitoring.
Hash cracking evaluates password strength offline. Fast hashes like md5 fall quickly; slow salted hashes like bcrypt and argon2 resist. This is why password storage must use slow hashes.
Privilege escalation comes in two flavors: vertical escalation gains higher privileges, horizontal escalation reaches other users at the same level. Patching, least privilege and audit logs defend both.
Linux privilege escalation basics: misconfigured sudo rules, writable system paths, cron jobs running as root, and SUID binaries. Auditing these is standard hardening.
Windows privilege escalation basics: unquoted service paths, weak service permissions, always install elevated policy, and stored credentials. Hardening guides cover each.
Social engineering tests the human layer: pretexting, baiting, tailgating, and phishing simulations run with permission build awareness.
Wireless security: WEP is broken, WPA2 with strong passphrases is acceptable, WPA3 is best. Rogue access points and evil twins are detected by monitoring.
Maintaining access is what attackers try next after entry: backdoors, new accounts, scheduled tasks. Defenders hunt these with file integrity monitoring and account audits.
Covering tracks means attackers clear logs and timestamps. Ship logs off-host in real time so cleaning local logs does not hide the intrusion.
A red team emulates real adversaries with creativity; a blue team defends and detects; a purple team makes them work together to improve controls.
Threat hunting starts from a hypothesis: an attacker would do X, so look for X in telemetry across endpoints, network and identity logs.
MITRE ATT&CK is a knowledge base of adversary tactics and techniques mapped from recon to exfiltration. Teams use it to plan detection coverage.
Vulnerability management cycle: discover assets, scan, prioritize by risk, patch or mitigate, verify, repeat.
A security baseline is a documented minimum configuration: CIS benchmarks give baselines for operating systems, clouds and databases.
Container security basics: minimal base images, no secrets in layers, non root users, image scanning, and read only file systems.
Cloud security shares responsibility: the provider secures the infrastructure, the customer secures configuration, identities and data. Misconfigured storage buckets remain a top leak source.
Always get authorization before testing systems you do not own. Unauthorized access is a crime even with good intentions.
